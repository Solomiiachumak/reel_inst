# reel_inst — автоматичні рілси Players get ready

Таблиця «контент-план» (вкладка «Рілси авто») → GitHub Actions (пошук відео на Pexels + рендер через ffmpeg) → готовий MP4 у папці на Google Drive.

## Як це працює

1. У вкладці «Рілси авто» вписуємо текст (переноси рядків через Alt+Enter зберігаються), ключові слова для відео англійською і ставимо статус **«в чергу»**.
2. Меню **Рілси → Згенерувати**: Apps Script запускає GitHub Actions для кожного такого рядка, статус стає «рендериться».
3. GitHub шукає вертикальне відео на Pexels (ті, що вже використовували, пропускає), рендерить рілс 1080×1920 і зберігає його як артефакт.
4. Кожні 5 хв Apps Script забирає готові рілси на Google Drive, ставить посилання і статус «готово».
5. Відео не підійшло? Ставимо статус **«інше відео»** і знову «Згенерувати»: буде нове відео з тим самим текстом.

## Файли

| Файл | Що це |
|---|---|
| `render_reel.py` | рендер: відео + сепія + затемнення + зерно + текст. Стиль змінюється в блоці `STYLE` |
| `pipeline.py` | пошук і завантаження відео на Pexels, виклик рендера, `meta.json` |
| `.github/workflows/render.yml` | запуск на серверах GitHub |
| `apps_script/Code.gs` | скрипт для Google-таблиці (вставляється в Apps Script, у репозиторії лише для зберігання) |
| шрифт і зерно | Roboto ставиться на сервері (пакет fonts-roboto), плівкове зерно генерується автоматично при першому запуску |

## Налаштування (один раз)

### 1. GitHub: ключ Pexels
Репозиторій → **Settings → Secrets and variables → Actions → New repository secret**
- Name: `PEXELS_API_KEY`
- Secret: ключ з https://www.pexels.com/api/

### 2. GitHub: токен для таблиці
Аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
- Repository access: **Only select repositories** → `reel_inst`
- Permissions → Repository permissions → **Actions: Read and write** (Metadata: Read додасться сам)
- Скопіювати токен (показується один раз).

### 3. Google-таблиця «контент-план»
1. **Розширення → Apps Script**, вставити вміст `apps_script/Code.gs`, зберегти.
2. **Налаштування проєкту (шестерня) → Властивості скрипта**, додати:
   - `GITHUB_TOKEN` — токен з кроку 2
   - `DRIVE_FOLDER_ID` — ID папки на Drive для рілсів (частина посилання після `/folders/`)
3. Оновити таблицю → з'явиться меню **Рілси**.
4. **Рілси → Створити вкладку «Рілси авто»** (перший раз Google попросить дозволи — дозволити).
5. **Рілси → Увімкнути автозбір кожні 5 хв**.

### 4. Перевірка
Вписати один рядок, статус «в чергу» → **Рілси → Згенерувати**. На GitHub у вкладці **Actions** з'явиться запуск «Рілс, рядок N» (~2–4 хв). Ще за кілька хвилин у таблиці з'явиться посилання на MP4.

## Локальний тест рендера

```bash
pip install -r requirements.txt   # + встановлений ffmpeg
REEL_TEXT="$(cat text.txt)" python3 pipeline.py --video bg.mp4 --out out/reel.mp4 --meta out/meta.json
```

## Ліміти
- GitHub Actions у приватному репозиторії: безкоштовна квота хвилин на місяць; один рілс ≈ 2–4 хв.
- Pexels API: безкоштовно, з лімітом запитів на годину — для 3 рілсів на день із запасом.
- Ліцензія Pexels дозволяє комерційне використання; автор відео записується в таблицю.
